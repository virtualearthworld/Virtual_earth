Video to 3D — inside Virtual Earth

Our goal is to let you select a video and create a 3D scene without leaving this page. This first in-page prototype uses a browser-based WebGPU reconstruction engine. The engine is currently loaded from a separate project, so it is displayed here but is not yet part of Virtual Earth's own source code.

Loading the in-page reconstruction workspace…

The reconstruction runs locally in a compatible browser with WebGPU; processing speed depends on your computer. For the fully self-contained version you asked for, the next engineering step is to bring this open-source engine's source and build into the Virtual Earth repository, rather than loading it from a separate website.

Current stage: The beach is still an illustration, but video frame extraction now works locally in this page. For full video-to-3D reconstruction, we found OOOSplat, a free, open-source desktop project that converts videos or image sequences into 3D Gaussian splats on your own computer. The browser demo cannot run that heavy desktop/GPU engine by itself, so the next integration step is connecting exported 3D scenes to this viewer. Check its Mac requirements before installing; its Apple Silicon Mac build is marked Alpha.
